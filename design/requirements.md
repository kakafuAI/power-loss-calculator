# 需求规格说明书

> 版本: v1.0.0 | 日期: 2026-05-14

## 1. 项目目标

构建 Web 版功率半导体器件损耗计算工具，支持多种器件类型的导通损耗、开关损耗计算及热分析，具备良好的交互性和可视化效果。

## 2. 功能需求

### 2.1 器件支持

| ID | 需求 | v1.0.0 |
|----|------|--------|
| F-01 | 支持 IGBT PIM 模块 | ✅ |
| F-02 | 支持 IPM 智能功率模块 | ✅ |
| F-03 | 支持 IGBT 单管 | ✅ |
| F-04 | 支持 SiC MOSFET 模块 | ✅ |
| F-05 | 支持 SiC MOSFET 单管 | ✅ |

### 2.2 拓扑支持

| ID | 需求 | v1.0.0 |
|----|------|--------|
| F-06 | 三相两电平逆变器（整流+逆变+制动斩波） | ✅ |
| F-07 | NPC 三电平 | 延后 |

## 3. 技术约束

| 约束 | 决策 |
|------|------|
| 前端框架 | React + TypeScript + Vite |
| UI 组件库 | Ant Design |
| 图表库 | ECharts (via echarts-for-react) |
| 后端框架 | Python FastAPI |
| 数值计算 | NumPy + SciPy |
| PDF 解析 | pdfplumber |
| 导出 | openpyxl (Excel) |
| 部署 | 前后端分离，Vite proxy 转发 API |
