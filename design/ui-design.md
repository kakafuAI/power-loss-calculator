# 界面设计文档

> 版本: v1.0.0 | 日期: 2026-05-14

## 1. 设计原则

- **渐进式引导**：4 步向导降低认知负荷
- **所见即所得**：参数变更实时反映在摘要卡片
- **透明计算**：每一步中间过程可展开查看
- **品牌无关**：不绑定特定厂商的 UI 范式

## 2. 信息架构

```
App
├── Header (Logo + 标题 + 版本号)
├── Sidebar (Steps 步骤导航)
│   ├── [1] 器件选择
│   ├── [2] 参数设置
│   ├── [3] 工况设置
│   └── [4] 计算结果
└── Main Content (当前步骤内容)
```

## 5. 交互规范

### 5.1 步骤导航

- 左侧 Steps 组件可点击跳转已完成的步骤
- 不可跳过未完成的步骤
- 计算结果出后可自由回退修改参数重新计算

### 5.2 参数验证

- 数值输入展示边界值提示
- PDF 上传后显示提取参数数量
- 缺失必要参数时"开始计算"按钮置灰

### 5.3 加载状态

- 计算中显示 Spin + "正在计算损耗..."
- 曲线扫描显示 Button loading
- PDF 解析显示进度提示

### 5.4 错误处理

- API 错误显示 message.error 通知
- 计算失败保留已输入参数，允许重试
- PDF 解析失败提示检查文件格式
