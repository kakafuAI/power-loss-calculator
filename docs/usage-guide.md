# 使用指南

## 界面导航

工具采用 4 步向导流程，左侧显示当前步骤：

```
[1] 器件选择 → [2] 参数设置 → [3] 工况设置 → [4] 计算结果
```

## 步骤 1：器件选择

选择需要计算的功率半导体器件类型：

| 器件类型 | 适用场景 | 损耗模型 |
|---------|---------|---------|
| IGBT PIM 模块 | 通用变频器、伺服驱动 | IGBT + FWD |
| IPM 智能功率模块 | 伺服驱动（内置驱动和保护） | IGBT + FWD |
| IGBT 单管 | 小功率或定制设计 | IGBT + FWD |
| SiC 模块 | OBC、DC/DC 变换器 | SiC MOSFET + 体二极管 |
| SiC 单管 | 高频开关电源 | SiC MOSFET + 体二极管 |

当前支持的拓扑：**三相两电平逆变器**（含三相整流 + 三相逆变 + 制动斩波）

## 步骤 2：参数设置

### 方式一：PDF 规格书自动提取

1. 将器件规格书 PDF 拖拽到上传区域
2. 系统自动识别厂商和型号
3. 提取关键参数并标记置信度：
   - 🟢 高置信度 (>80%)：明确匹配
   - 🟠 中置信度 (50-80%)：多匹配或弱模式
   - 🔴 低置信度 (<50%)：估计值，需手动确认
4. 自动填充到手动输入表单中

### 方式二：手动输入

展开折叠面板填入参数：

**基本参数**
- 模块名称、制造商
- 额定电压 Vce/Vds、额定电流 Ic/Id
- Vce(sat) @ 25°C 和 125°C（IGBT）或 Rds(on)（SiC）

**二极管参数**
- Vf @ 25°C 和 125°C
- 反向恢复电荷 Qrr

**开关损耗参数**
- Eon、Eoff、Err 数据点（电流, 能量 mJ 对）
- 参考条件：Vcc、Rg、Tj
- 支持添加/删除数据点

**热参数**
- Rth(j-c) IGBT / Diode
- Rth(c-s) 模块级
- Rth(s-a) 散热器

## 步骤 3：工况设置

| 参数 | 范围 | 说明 |
|------|------|------|
| Vdc | 100 - 1500V | 直流母线电压 |
| I_out | 1 - 200A | 输出电流 RMS |
| f_sw | 0.5 - 50kHz | 开关频率（载波频率） |
| f_out | 1 - 400Hz | 输出基波频率 |
| m | 0.1 - 1.15 | 调制比 |
| cos φ | 0.1 - 1.0 | 负载功率因数 |
| Tamb | -20 - 80°C | 环境温度 |

右侧摘要卡片实时显示换算后的峰值电流等参数。

点击 **开始计算** 提交计算请求。

## 步骤 4：计算结果

结果面板包含 5 个标签页：

### 总览
- 6 个摘要卡片：总损耗、效率、输出功率、最高结温、壳温、收敛状态
- 损耗分布饼图：IGBT/二极管导通/开关损耗占比
- 器件损耗柱状图：12 个器件（6 IGBT + 6 二极管）的损耗堆叠
- 损耗汇总表和每相电流统计

### 器件详情
- 12 个器件的详细损耗表格
- 包含：导通损耗、开关损耗、总损耗、结温
- 结温颜色指示：
  - 🟢 正常（< 85% Tj_max）
  - 🟠 警告（85% - 100% Tj_max）
  - 🔴 超限（> Tj_max）
- 底部显示汇总行

### 计算过程
- 7 个可折叠步骤卡片：
  1. 输入参数回显
  2. 导通损耗计算（含平均电流、RMS 电流、等效占空比）
  3. 二极管导通损耗计算
  4. 开关损耗计算（含每次开关的平均能量 mJ）
  5. 热迭代收敛过程表格
  6. 总损耗汇总

### 波形
- 调制信号正弦波
- 输出电流波形（含功率因数角偏移）
- 上管占空比曲线（含填充区域）
- 用于直观理解 IGBT/二极管导通区间

### 特性曲线
点击按钮生成参数扫描曲线：
- **损耗 vs 输出电流**：固定 Vdc、fsw、pf 下扫描 Iout
- **损耗 vs 开关频率**：展示开关损耗在高频下的主导地位
- **损耗 vs 功率因数**：功率因数对损耗分布的影响

每条曲线包含：
- 总损耗
- IGBT 导通/开关损耗分量
- 二极管导通/开关损耗分量
- 效率曲线
- 最高结温曲线

### 热迭代详情
- 每次迭代的完整数据表
- 散热器温度、壳温、各器件结温
- 每相损耗分量
- Tj 变化量（判断收敛趋势）

## 结果导出

- **Excel**：多工作表工作簿
  - Sheet 1: 汇总（损耗、效率、结温）
  - Sheet 2: 器件详情（12 个器件的完整数据）
  - Sheet 3: 计算步骤（含热迭代日志）
- **CSV**：单文件，包含汇总和器件列表

## 典型工作流程示例

### 示例 1：英飞凌 FS100R12KT4 模块评估

1. 选择 "IGBT PIM 模块"
2. 上传 FS100R12KT4 规格书 PDF，自动提取参数
3. 检查自动提取的参数，手动补充开关能量数据点：
   - Eon: (10A, 5mJ), (50A, 25mJ), (100A, 55mJ)
   - Eoff: (10A, 3mJ), (50A, 15mJ), (100A, 35mJ)
4. 设置工况：Vdc=600V, Iout=50A, fsw=4kHz, cosφ=0.85
5. 点击计算，查看结果
6. 在总览页确认 Tj_max 是否在 150°C 以内
7. 生成特性曲线，找到安全工作区间
8. 导出 Excel 报告

### 示例 2：SiC MOSFET 模块高频应用评估

1. 选择 "SiC 模块"
2. 手动输入 Rds(on)=20mΩ@25°C, 35mΩ@125°C
3. 输入开关能量：Eon=2mJ, Eoff=1.5mJ @ 100A/800V
4. 设置高频工况：fsw=20kHz, Iout=30A
5. 对比不同开关频率下的损耗分布
6. 利用特性曲线找到最优工作点

## 参数参考值

以下为典型 1200V/100A IGBT 模块的参考参数：

| 参数 | 典型值 | 单位 |
|------|--------|------|
| Vce(sat) @ 25°C | 1.5 - 1.8 | V |
| Vce(sat) @ 125°C | 1.8 - 2.2 | V |
| Eon @ 100A/600V | 10 - 20 | mJ |
| Eoff @ 100A/600V | 8 - 15 | mJ |
| Vf @ 25°C | 1.6 - 2.0 | V |
| Err @ 100A/600V | 6 - 12 | mJ |
| Rth(j-c) IGBT | 0.15 - 0.30 | K/W |
| Rth(j-c) Diode | 0.30 - 0.50 | K/W |
| Rth(c-s) Module | 0.02 - 0.05 | K/W |
